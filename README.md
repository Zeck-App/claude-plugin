# Zeck

Use Claude to prepare for a board meeting with the materials your team keeps in Zeck. Connect the plugin and sign in with your existing Zeck account. Ask “What went better or worse than planned in my latest published Zeck?” or “Compare my two latest published Zecks and link to the sections you used.”

The plugin connects to Zeck’s production MCP server. Zeck checks your permissions for each request. You can read published materials and inspect the working copies you have access to. When the server offers editing tools and you have editing permission, you can also ask Claude to revise an unpublished section. Open the returned editor link to review your changes and publish in Zeck.
